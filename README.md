## Особенности

* **Простой и тёмный UI**: Удобный графический интерфейс в стильном тёмном дизайне.
* **Выбор качества видео**: Поддержка скачивания в разрешении **360p**, **720p** и **1080p**.
* **Выбор папки**: Возможность указать любую удобную директорию для сохранения файлов.
* **Индикатор прогресса**: Отслеживание процента загрузки видео в режиме реального времени.

Запустить build.bat
